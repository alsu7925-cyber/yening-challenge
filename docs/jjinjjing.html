미리보기찐찡이네 서식 · 15pt

💡 끝인사는 넣지 않아요 — 마무리는 직접 써 주세요. 붙여넣은 뒤 네이버 전용 인용구 박스만 필요하면 에디터에서 인용구 버튼을 한 번 눌러 주세요. (형광펜·굵기·소제목·구분선은 그대로 들어갑니다)

이렇게 쓰면 돼요
  1. 원고를 통째로 원고 칸에 붙여넣어요.
  2. 오른쪽 미리보기에서 서식 확인 (짧은 줄이 소제목이 됐는지 보면 돼요).
  3. 📋 서식째 복사 → 네이버 글쓰기 화면에 Ctrl+V.
  4. 사진은 📸 사진 배치기 탭에서 묶음별로 받아 넣으면 끝!

소제목이 아닌 줄이 소제목이 됐다면 그 줄 끝에 마침표를 찍거나, # 없이 그냥 두고 자동 서식 다듬기를 잠깐 꺼서 복사하면 됩니다.

사진을 올리면 역할(외관·내부·메뉴판·메인·디테일)을 알아보고, 네이버 슬라이드 묶음으로 묶어 원고 어디에 넣을지 알려드려요. 묶음별 ZIP으로 받아 에디터에 바로 넣으면 끝!

📦 ZIP은 슬라이드마다 폴더로 담겨요. 에디터에서 사진 추가 → 폴더 열기 → Ctrl+A → [슬라이드]를 누르면 묶음이 슬라이드 1개로 들어갑니다.

사진 배치, 이렇게 하면 돼요
  1. 사진을 여러 장 한 번에 올려요 (촬영시간 순으로 자동 정렬).
  2. 사진 아래 역할을 확인하고, 틀린 것만 바꿔 주세요.
  3. 원고 칸에 글을 붙여넣고 ✨ 자동 배치.
  4. 🗂 전체 사진 ZIP을 풀면 01_슬라이드_도입부 같은 폴더가 생겨요.
  5. 네이버 글쓰기 → 사진 넣을 자리에 커서 → 사진 추가 → 그 폴더에서 Ctrl+A → 열기 → [슬라이드].

사진은 브라우저 안에서만 다뤄요 (어디에도 올라가지 않아요). 페이지를 닫으면 목록이 사라지니, 작업이 끝나면 ZIP을 먼저 받아 두세요.
